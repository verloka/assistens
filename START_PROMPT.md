# Copy-paste prompt for your coding agent

Ты реализуешь Personal AI Desktop Agent на Windows/.NET. В этой папке находятся спецификация `docs/DEVELOPMENT_PLAN_v1.1.md`, инструкции `AGENTS.md`, каталог `tasks.json` и состояние `progress/state.json`.

1. Прочитай `AGENTS.md` и все остальные упомянутые файлы. Сверяйся с полной спецификацией.
2. Выполни `scripts/taskctl.ps1 -Action doctor`, затем `-Action next`; сначала продолжай `in_progress` задачу, если она есть. Иначе начни первую доступную задачу.
3. Для задачи, влияющей на сквозное поведение, найди связанные FDD flow IDs в `docs/flows/index.md`; используй `$flow-develop` перед кодом и `$flow-verify` после изменений. Проверь обратные зависимости и сценарии; `Draft` не переводи в `Active` без моего явного подтверждения.
4. Реализуй одну завершённую функциональную единицу (задачу), с минимальными изменениями, тестами и всеми её acceptance criteria.
5. Не помечай `done`, пока реально не проверил критерии. Используй `scripts/taskctl.ps1 -Action done -Id ... -Evidence ... -Test ...`.
6. Каждую итерацию дополняй `progress/LOG.md` и `progress/CHECKPOINT.md`, по возможности коммить код и статус вместе.
7. Если для конкретной проверки требуются недоступные ключи, реальный Windows GUI или корпоративные права, пометь задачу `blocked` с объяснением и переходи к следующей доступной задаче. Не имитируй успешные тесты.
8. Соблюдай строгую модульность Core/Agent/Computer/MCP/Channel, безопасность Computer Use и приоритет пользовательского контроля компьютера.
9. Повторяй цикл задач, пока существуют незавершённые доступные задачи или пока я тебя не остановлю. В конце текущей сессии оставь точный checkpoint; не обещай работу в фоне после завершения сессии.
